# /list-plans - プラン一覧

`.claude/plans/` のプランファイルを一覧表示する。

## 手順

1. **ファイル一覧を取得**
   `.claude/plans/*.md` を日付降順（ファイル名の YYYY-MM-DD 部分）でソート

2. **一覧を表示**
   各ファイルについて:
   - ファイル名（日付 + タイトル）
   - 先頭の見出し行（`#` で始まる行）
   - Context セクションの先頭 3 行

3. **詳細表示**
   - ユーザーが選択したプランの全文を表示

## 注意事項

- ファイルがない場合は「プランファイルがありません」と報告
- ロードマップ (00-roadmap) と個別プランは区別して表示する
