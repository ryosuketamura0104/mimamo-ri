# /search-knowledge - ナレッジ横断検索

プラン、レポート、ADR を横断的に検索する。

## 手順

1. **検索キーワードを確認**
   - 引数がなければユーザーに検索キーワードを聞く

2. **横断検索を実行**
   以下の 3 箇所を grep で検索:
   - `.claude/plans/` - 実装プラン
   - `.claude/reports/` - 作業レポート
   - `.claude/adr/` - 設計判断記録

3. **結果を表示**
   - マッチしたファイルのパスとタイトル（先頭行）
   - 該当行のコンテキスト（前後 2 行）
   - ヒット数のサマリー

4. **詳細表示**
   - ユーザーが選択したファイルの全文を表示

## 注意事項

- 大文字小文字を区別しない
- 日本語キーワードにも対応
