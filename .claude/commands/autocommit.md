# /autocommit - 自動コミット

変更を適切な粒度に分割し、適切なコミットメッセージを付けてコミットする。

## 手順

1. **変更状況を確認**
   ```bash
   git status
   git diff
   git diff --staged
   ```

2. **変更を分析**
   - 変更されたファイルの内容を確認
   - 論理的なまとまりごとにグループ化（server / ios / android / .claude / adr / plans 等）
   - 各グループに適切なコミットメッセージを考える

3. **コミットメッセージの規約**
   - 日本語で記述
   - 絵文字は使用しない
   - プレフィックスを使用:
     - `feat:` 新機能
     - `fix:` バグ修正
     - `docs:` ドキュメント
     - `style:` フォーマット変更
     - `refactor:` リファクタリング
     - `test:` テスト
     - `chore:` その他

4. **コミット実行**
   - 各グループごとに `git add` と `git commit` を実行
   - コミットメッセージの末尾に以下を追加:
     ```
     Co-Authored-By: Claude <noreply@anthropic.com>
     ```

5. **結果を報告**
   - 作成したコミットの一覧を表示

## 注意事項

- push は行わない（/push コマンドを使用）
- 変更がない場合は「コミットする変更がありません」と報告
- `.env` 等の秘密ファイルを誤って含めないよう `git add -A` は避け、明示的にファイルを指定する
