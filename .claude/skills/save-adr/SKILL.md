# 設計判断の保存（ADR）

現在の会話で確定した設計判断を整理し、`.claude/adr/` にADRとして保存する。

## 手順

1. `.claude/adr/README.md` の記録一覧を確認し、次のADR番号を採番する
2. 既存ADRと矛盾・重複しないか確認する。既存判断の変更なら新規作成ではなく該当ADRを更新し、旧内容は「廃止」ステータスで残す
3. `README.md` のテンプレートに従って `ADR-XXXX-<英語スラッグ>.md` を作成する
   - **コンテキスト**には調査で判明した事実（数値・API制約・出典URL）を必ず含める
   - **検討した選択肢**には却下案とその理由も残す（将来の蒸し返し防止）
4. `README.md` の記録一覧に1行サマリ付きでリンクを追加する

## 書き方の注意

- 「なぜそうしたか」が主役。実装の詳細はコードに任せる
- 不確かな情報（未検証のOS挙動等）は断定せず「要スパイク検証」等と明示する
- 日本語で記述、絵文字禁止
