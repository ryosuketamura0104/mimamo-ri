# Plan 05: Webダッシュボード（見守る側）+ 管理画面

## Context

Plan 01 の `server/` Next.js に同居させる。picolin-server の画面構成・コンポーネント規約を踏襲。
アカウント作成はアプリ内とWebの両方から可能（要件）。

## 1. 見守る側ダッシュボード（`app/(watcher)/`）

- Firebase Auth ログイン/サインアップ（Web起点のアカウント作成に対応。ロール選択→watcherのみWebで完結、watchedはアプリDLへ誘導）
- 見守り対象一覧: 状態バッジ（正常/確認中/アラート/端末オフライン）、最終シグナル時刻、シグナル種別の内訳
- 対象詳細: シグナルのタイムライン表示（直近7日）、アラート履歴、最終位置の地図
- 設定編集: T（しきい値時間）、静穏時間帯、区間刻み、通知先
- Widgetメッセージ送信フォーム
- アラートの解消操作

## 2. 管理画面（`app/admin/`）

- 管理者ロール（usersにisAdmin追加 or 別テーブル。picolinの admin 実装を参考）
- ユーザー・ペアリング一覧/検索、エスカレーション発生状況の横断ビュー
- シグナル受信の全体モニタリング（直近の受信レート、途絶判定cronの実行ログ）
- サブスク状況（Plan 06 実装後に拡張）

## 3. 通知

- 見守る側への通知はモバイルプッシュが主だが、Webのみのwatcher向けに**メールアラート**を用意（picolinのSES実装を流用可）。watch_settingsに通知チャンネル設定を追加

## 完了条件

- watcherがWebだけで登録→招待コード発行→状態確認→アラート受信（メール）→解消まで完結できる
