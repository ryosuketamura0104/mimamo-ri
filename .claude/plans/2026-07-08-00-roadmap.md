# mimamo-ri 全体ロードマップ

## Context

一人暮らし見守りアプリ。設計判断は `.claude/adr/ADR-0001-survival-detection-design.md` に確定済み。
プロダクト前提は `.claude/CLAUDE.md` を参照（見守る側/見守られる側の分離、見守る側のみRevenueCatサブスク、SOSはファーストリリース外）。

## フェーズと依存関係

```
Phase 0: iOSスパイク（DeviceActivity実機検証）  ← 検知設計の成立確認。最優先
Phase 1: server土台（スキーマ+シグナルAPI+途絶判定）  ← Phase 0と並行可
Phase 2: iOSアプリ本体+拡張群 / Androidアプリ  ← Phase 1のAPIに依存
Phase 3: Webダッシュボード+管理画面  ← Phase 1に依存、Phase 2と並行可
Phase 4: 課金（RevenueCat）  ← Phase 2/3の後
```

## ファーストリリースのスコープ

- 含む: 生存検知（多層シグナル+2段階エスカレーション）、見守る側への通知、Widget（天気 or 見守る側からのメッセージ）、ペアリング、Webダッシュボード、管理画面、サブスク課金
- 含まない: SOS駆けつけ、通知フィルタリングエンタイトルメント（passive通知で代替）

## 未決事項
