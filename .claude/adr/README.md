# 設計判断記録（ADR - Architecture Decision Records）

重要な設計判断を記録します。「なぜそうしたか」を残すことで、将来の変更時に判断の根拠を参照できます。

## テンプレート

```
# ADR-XXXX: <タイトル>

## ステータス
承認 / 提案中 / 却下 / 廃止

## コンテキスト
何が問題・課題だったか

## 検討した選択肢
1. 選択肢A: 説明、メリット/デメリット
2. 選択肢B: 説明、メリット/デメリット

## 決定
どの選択肢を選んだか

## 理由
なぜその選択肢を選んだか

## 影響
この決定により何が変わるか
```
